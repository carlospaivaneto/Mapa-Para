Este repositório contém arquivos GeoJSON com dados geográficos do **estado do Pará**, da vibrante cidade de **Belém**, e de **pontos de interesse cruciais para a Conferência das Nações Unidas sobre as Mudanças Climáticas (COP30)**, sediada em Belém.

![mapa Pará](https://raw.githubusercontent.com/carlospaivaneto/Mapa-Para/refs/heads/main/Screenshot_20250430_200952_Chrome.jpg)

## 🗺️ Conteúdo dos Arquivos

Aqui você encontrará dados geográficos estruturados em formato GeoJSON, prontos para serem utilizados em diversas aplicações de mapeamento e análise espacial.

* **`para.geojson`**: Contém a representação geométrica de todos os **municípios do estado do Pará**. Ideal para visualização do panorama estadual e análises regionais.
* **`belem.geojson`**: Apresenta a geometria do **município de Belém**, permitindo um foco detalhado na cidade anfitriã da COP30.
* **`pontos_cop30_belem.geojson`**: Destaca os **principais pontos de interesse em Belém para a COP30**, incluindo:
    * **Hangar Centro de Convenções da Amazônia**: Principal local de eventos.
    * **Aeroporto Internacional de Belém/Val-de-Cans (BEL)**: Principal porta de entrada aérea.
    * **Estação das Docas**: Importante ponto turístico e potencial área de eventos.
    * **Centro de Belém**: Ponto de referência central da cidade.

## 🚀 Utilização dos Dados

Os arquivos GeoJSON podem ser facilmente integrados em:

* **Plataformas de visualização de mapas online**: Como Leaflet, Mapbox GL JS, e outras.
* **Sistemas de Informação Geográfica (SIG)**: Como QGIS, ArcGIS, e gvSIG para análise espacial detalhada.
* **Desenvolvimento web e mobile**: Para criar aplicações interativas com informações geográficas relevantes para a COP30.
